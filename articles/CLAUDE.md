# articles

Insights blog posts. `src/<slug>.md` is the source a writer edits; `<slug>.html` is generated from it and committed by CI. The filename is the public URL (`/articles/<slug>.html`, served by Cloudflare Pages as `/articles/<slug>` too).

## Contents
| Path | Purpose |
|------|---------|
| `src/README.md` | The writer guide, rendered by GitHub at the top of the folder. Plain language; keep it that way. |
| `src/<slug>.md` | Article source. Front matter between `---` lines: `title`, `description`, `author`, `date` (YYYY-MM-DD); optional `card` (card text on blog and homepage if different from the description), `updated` (YYYY-MM-DD, becomes `article:modified_time`, `dateModified`, and sitemap `lastmod`). Body is Markdown, first paragraph becomes `p.lead`. |
| `<slug>.html` | Generated by `../.github/scripts/render-articles.mjs` from the template in `../.github/templates/article.html`. Carries a `<!-- generated from articles/src/... -->` marker. Do not hand-edit; the next deploy overwrites it. A generated page whose source is deleted is removed by the renderer. |
| `what-a-plan-document-tool-must-do.{md,html}` | The one published article (26 August 2026, bylined "SyncroDoc Systems"). When `author` is exactly `SyncroDoc Systems`, the byline has no "By" and JSON-LD author is the Organization; any other author renders "By Name" and a Person. |

## Relationships
- **Parent**: sub-page of the marketing site. Shares `../article.css` and `../logo.png` with `../blog.html` and `../deck.html`.
- **Listed in**: `../blog.html` (all) and `#insights` in `../index.html` (three newest), regenerated from each page's `og:title`, `og:description`, `article:published_time` by `../.github/scripts/build-article-lists.mjs`. Also `../sitemap.xml`.
- **Checked by**: `../.github/scripts/lint-article.mjs` (front matter, date, description length, dashes, banned words, no HTML, heading levels, no absolute site links) and html-validate on the rendered output, both run by `content-lint.yml` on every PR.

## Conventions
- Markdown only in sources. `##` and `###` headings, `-` bullets, `>` single-paragraph pull quotes (rendered as a bare `<blockquote>` to match the CSS), `**bold**`, links. No raw HTML, no code fences, no images yet.
- Relative links to the site (`../index.html#start`, `../blog.html`). The lint rejects absolute `https://syncrodocsystems.com` links in bodies.
- Page `<title>` is `{{title}} — SyncroDoc`; the em dash lives in the template. Sources may not contain em or en dashes anywhere.
- US spelling. No client, plan, fund, or vendor names. Banned-word list is the `BANNED` array in `lint-article.mjs`.

## Warnings
- `src/` and the old `_TEMPLATE` URLs are 302-redirected to `/blog` by `../_redirects`; keep those lines.
- Renaming a source renames the page. Add a redirect in `../_redirects` if a published slug must change.
- Non-owner PRs may only add or edit `src/<slug>.md` (paths guard). Deleting or renaming an article is an owner task.
